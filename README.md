# Amino Orbit · Private development ZIP builds

Installable WordPress plugin packages for **Amino #LAB**, built from the [main development branch](https://github.com/aminostudio/amino-orbit/tree/main).

## Available versions

- **[amino-orbit-0.3.5.zip](amino-orbit-0.3.5.zip)** · repairs French and Spanish gettext MO headers for WordPress 6.4 while preserving compatibility with newer WordPress. All PHP 8.0/8.2/8.4, WordPress 6.4 and current WordPress, browser and Plugin Check suites passed in [CI #48](https://github.com/aminostudio/amino-orbit/actions/runs/43563598946). No runtime feature changes.
- [amino-orbit-0.3.4.zip](amino-orbit-0.3.4.zip) · keyboard focus-safe AJAX refresh.
- [amino-orbit-0.3.3.zip](amino-orbit-0.3.3.zip) · distinct native WordPress session identities.
- [amino-orbit-0.3.2.zip](amino-orbit-0.3.2.zip) · less redundant daily cleanup.
- [amino-orbit-0.3.1.zip](amino-orbit-0.3.1.zip) · bounded session scan.
- [amino-orbit-0.3.0.zip](amino-orbit-0.3.0.zip) · localization and accessibility.
- [amino-orbit-0.2.1.zip](amino-orbit-0.2.1.zip) · 30-second optional refresh.
- [amino-orbit-0.2.0.zip](amino-orbit-0.2.0.zip) · early dashboard refinements.

Install by WordPress **Plugins → Add New → Upload Plugin** if an upgrade is desired; each ZIP has one `amino-orbit/` root directory. **v0.3.5 is a private compatibility update, not a public release.**

**Amino #LAB remains on v0.3.4** until explicitly upgraded. There is no urgency to replace the plugin on a recent WordPress where v0.3.4 translations already worked.
