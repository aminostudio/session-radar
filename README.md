# Amino Orbit · Development downloads

This branch provides installable ZIP packages for **Amino #LAB**. The WordPress plugin source and development tests remain on [main](https://github.com/aminostudio/amino-orbit).

## Available packages

- [amino-orbit-0.2.1.zip](amino-orbit-0.2.1.zip) · optional 30-second widget refresh; 60 seconds remains the default.
- [amino-orbit-0.2.0.zip](amino-orbit-0.2.0.zip) · previous development build.

Each ZIP contains a single top-level `amino-orbit/` directory. Install through **Plugins → Add New → Upload Plugin**, then choose to replace the installed version.

**Status:** Development builds only; no public stable release yet.
